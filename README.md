# NIVEAU −3

Jeu d'horreur 3D en vue subjective, jouable dans le navigateur (Three.js).

**Jouer : https://imowwgli.github.io/niveau-3/**

## Mode histoire (solo)

Tu es enfermé au niveau −3. Trouve les 5 fusibles, remets le courant sur la grille de sortie, et sors. Tu n'es pas seul.

## Mode zombies — INFESTATION (coop, 1 à 4 joueurs)

Vagues de zombies de plus en plus nombreuses et rapides. Gagne des points en tirant, achète des armes et des munitions, relève tes potes à terre.

Pour jouer à plusieurs : un joueur clique sur « Créer un salon » et donne le code à 4 lettres aux autres, qui cliquent sur « Rejoindre ». La connexion est en pair-à-pair (WebRTC via PeerJS), sans serveur de jeu.

## Commandes

| Touche | Action |
|---|---|
| Z Q S D | se déplacer |
| Souris (ou ← →) | regarder |
| Maj | courir |
| F | lampe torche |
| E | interagir / acheter / relever un allié |
| Clic gauche | tirer (mode zombies) |
| R | recharger (mode zombies) |
| 1 / 2 ou molette | changer d'arme (mode zombies) |

## Crédits
