# NIVEAU −3

Jeu d'horreur 3D en vue subjective, jouable dans le navigateur (Three.js, tout est procédural : textures, sons, créature).

Tu es enfermé au niveau −3. Trouve les 5 fusibles, remets le courant sur la grille de sortie, et sors. Tu n'es pas seul.

## Commandes

| Touche | Action |
|---|---|
| Z Q S D | se déplacer |
| Souris (ou ← →) | regarder |
| Maj | courir (il t'entend) |
| F / clic droit | lampe torche |
| E | interagir |

Casque audio recommandé. Le jeu tient dans un seul fichier : `index.html`.
